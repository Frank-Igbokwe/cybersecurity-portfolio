CTF Write-Up: Port Knocking Challenge

6/6 Flags

Analyzed PCAP traffic (10.10.177.226 ↔ 10.10.177.228) using Wireshark/TShark and Scapy to decode hex-encoded ICMP Type 16 flag payloads across six knocking tasks: ICMP Echo (Type 8), UDP ports 75, 31, and 31337, UDP echo/chargen (ports 7 and 19), and ICMP Type 15 Information Request carrying a custom payload. Built an AsyncSniffer workflow to capture asynchronous responses alongside ICMP Port Unreachable traffic.

  • Tools: Scapy, TShark/Wireshark, tcpdump, Python
